# Adverse Action & Reason Code Policy

## adverse-action#principal-reasons
When an application is declined, the applicant must receive the principal reasons
for the decision. Reasons must be specific, accurate, and based on the factors
that most influenced the model's risk estimate — not generic statements. Cite the
top contributing factors from the model's driver attribution.

## adverse-action#debt-to-income
A high debt-to-income ratio is a valid principal reason for decline. It indicates
that existing obligations consume a large share of income, reducing capacity to
service new debt. Reference the applicant's elevated debt-to-income ratio when it
is among the top risk drivers.

## adverse-action#delinquencies
Recent delinquencies are a valid principal reason for decline. A pattern of missed
payments is predictive of future default. When delinquencies are a top driver, the
reason code should state that recent delinquencies increased estimated risk.

## adverse-action#credit-utilization
Elevated credit utilization — a high ratio of balances to available credit — is a
valid principal reason. It signals credit stress. Reference it when it ranks among
the top drivers.

## adverse-action#prohibited-basis
A reason code must never cite a protected attribute (such as the applicant's group
membership) or any proxy for it. Protected attributes are excluded from the model
and from all explanations.
